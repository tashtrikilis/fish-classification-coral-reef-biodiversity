# Presentation figures

Each notebook makes the slide figures for one part of the talk. The numbers are written into the notebooks, so they
run anywhere with `matplotlib`. Set `THEME = 'light'` or `'dark'` at the top.

| Notebook | Figures |
|---|---|
| `presentation_figures.ipynb` | all 12 main slide figures (needs `report_figures/` images and `dataset/images/`) |
| `class_imbalance.ipynb` | class distribution |
| `rq1_figures.ipynb` | finding fish vs species, model size, detection vs segmentation |
| `rq2_figures.ipynb` | focus-species gains, per species, consistency across runs, error breakdown |
| `nontarget_figures.ipynb` | non-target and any-fish changes, augmentation vs a bigger model |
| `efficiency_table.ipynb` | computational cost table |
| `cv_simple.ipynb`, `cv_folds_deck.ipynb` | cross-validation fold diagram (the deck version uses Inter from `fonts/`) |
